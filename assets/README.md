# assets

`icon.png` — 512×512, the Yopass logo, taken from the Yopass Raycast extension
(`ricoberger/yopass`) in the MIT-licensed [`raycast/extensions`](https://github.com/raycast/extensions)
repository, so this extension looks like the tool it talks to.

It is not this project's artwork, and this project is not affiliated with the Yopass maintainers.
Yopass itself lives at [jhaals/yopass](https://github.com/jhaals/yopass) (Apache-2.0).

If you fork this and the icon bothers you or its licence is ever unclear, replace this file — the
manifest only requires `assets/icon.png` to exist as a 512×512 PNG.
